## 1. Project Description

The Extreme IT Products Management System is a Java console application developed in **NetBeans** to manage IT products. It allows users to add, search, update, delete, and view product information.

The system uses Object-Oriented Programming concepts and is divided into different classes, with each class having a specific purpose.

## 2. Project Features

The system allows users to:

* Add new products.
* Search for products using a product code.
* Update warranty, price, and stock.
* Delete products after confirmation.
* View a report of all products.
* Navigate the system using a menu.
* Check and handle incorrect input.

## 3. Project Structure

The project has three main classes:

**Main:** Starts the application and displays the main menu.

**Products:** Handles adding, searching, updating, deleting, and displaying products.

**ReportData:** Stores product details such as the product code, name, category, warranty, price, and stock.

## 4. How to Run the Application in NetBeans

1. Open **NetBeans**.
2. Open the Extreme IT Products Management System project.
3. Make sure all the required classes are included.
4. Build the project and check for errors.
5. Run the **Main** class.
6. Use the menu options to operate the system.

## 5. Terminologies Used

**Java:** The programming language used to develop the application.

**NetBeans:** The development environment used to create, edit, build, and run the Java application.

**Object-Oriented Programming:** A programming approach that uses classes and objects.

**Class:** A structure used to organise related information and functions.

**Object:** A specific item created from a class, such as a product.

**ArrayList:** Used to store product information while the application is running.

**Encapsulation:** Keeps data protected within a class.
